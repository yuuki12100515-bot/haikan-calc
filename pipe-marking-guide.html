配管の円周と等分罫書きガイド

配管外周に穴位置や取付位置を罫書く際は、直径と円周の関係を確認します。

円周と等分ピッチ

外径 D の円周 C は C = π × D です。円周を n 等分したときの外周に沿ったピッチは C ÷ n となります。

例：外径100mmの円周は約314.16mm。4等分した外周ピッチは約78.54mmです。これは円周に沿った距離で、直線の弦長とは異なります。

罫書きの注意点

  1. 呼び径ではなく実際の外径を使う
  2. 円周方向のピッチと直線距離を混同しない
  3. 基準線と管端直角を確認する
  4. 現物で等分位置が一周して一致するか確認する
